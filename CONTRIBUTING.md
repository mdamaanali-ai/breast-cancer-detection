# Contributing

1. Create a feature branch.
2. Keep preprocessing leakage-safe.
3. Add or update tests for changed inference behavior.
4. Run `pytest -q` and `python -m compileall src scripts app.py predict.py train_model.py`.
5. Open a pull request with a concise description of the change.

This repository is an educational ML project. Do not present it as a clinically validated diagnostic system.
